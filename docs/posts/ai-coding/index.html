AI coding

December 17, 2025
  • ai

I'll probably get called a heretic for saying this, but: too much has been made of AI coding. I think there are only 5 things you need to know. The rest is noise.

  1. Assistive coding is a tool that gives you an average 20% productivity boost. † And like any other tool, you should use it when it makes sense and abstain when it doesn't.

  2. It's unlikely that natural language programming will displace code. Today's narrative that anyone can write production-ready software using English is no different than the hopes pinned on COBOL, UML, and fourth-generation languages. Yet here we are with a large engineering job market.

  3. Rapid prototyping with AI is a superpower, but prototyping isn't the majority of a software engineer's job. Your life's work is to create big, complex business systems that have never been built before, not launch 12 mostly-finished Pac-Man apps.

  4. There is a huge influx of AI apps, and they fall into two categories. The first are those that use machine learning for tasks that used to be difficult to solve. The second are those that use machine learning for tasks because it's cool. The former are highly durable; the latter will disappear in a few years.

  5. Anyone who specializes in generating piles of low-quality code doesn't have a long-term future in software engineering.

† 20% is my subjective observation from talking with > 100 engineers across many different kinds of tasks.
