😮 Modern Java is a COMPLETELY different language than the one most of us grew up with.  

![](/img/modern-java.png)

On the left is Java 7. On the right is 25. Besides being shorter, the substance of 25 is completely different:  

(1) record types to minimize boilerplate code  
(2) streaming API for map/filter/reduce  
(3) anonymous functions  
(4) immutability by default  
(5) pattern matching  
(6) type inference on local variables  

All of these constructs make programs easier to read and write. And if that wasn't enough, modern Java now has:  
- virtual threads  
- an embedded HTTP Client  
- functional interfaces  

Plus a whole lot more.  

It's a good time to be on the JVM.
